## Purpose

The purpose of this 16-week AI Literacy Layer is to build a basic understanding of AI and learn how to use AI tools properly in engineering work.

During this program, I will learn AI concepts, understand how LLMs work, verify AI-generated information, and learn how AI can support engineering tasks.
