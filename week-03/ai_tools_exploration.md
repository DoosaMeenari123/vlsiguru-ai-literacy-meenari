# AI Tools Exploration

## 1. Introduction

Artificial intelligence tools can support technical learning, research, coding, and problem-solving. They can explain difficult concepts in simple language and help organise information into tables, diagrams, and step-by-step instructions.

However, AI tools may produce incorrect or incomplete answers. Therefore, I should verify important claims using official documentation and other reliable sources.

## 3. What Is Prompt Engineering?

Prompt engineering means writing and refining instructions to obtain a more useful response from an AI tool.

A good prompt can include:

- **Context:** What topic or problem I am studying.
- **Task:** What I want the AI tool to explain or solve.
- **Constraints:** The level of detail or limitations.
- **Output format:** A table, list, diagram, or code example.
- **Verification:** A request for sources or supporting evidence.

## 4. Prompt Improvement Experiments

### Experiment 1: Understanding Physical Design

**Basic prompt:**

```text
Explain Physical Design in VLSI.
```

**Improved prompt:**

```text
Explain Physical Design in VLSI for a beginner. Describe
floorplanning, placement, clock tree synthesis, routing,
and timing analysis in simple language. Present the
explanation in a Markdown table with the purpose of each stage.
```

**Expected improvement:** The improved prompt gives the AI a clear audience, specific topics, and a required output format.

### Experiment 2: Learning Python

**Basic prompt:**

```text
Explain Python loops.
```

**Improved prompt:**

```text
Explain for loops and while loops in Python for a beginner.
Provide one simple example of each, explain every line,
and show the expected output.
```

**Expected improvement:** The improved prompt requests examples and explanations rather than only a general definition.

### Experiment 3: Investigating a VLSI Tool

**Basic prompt:**

```text
Explain OpenROAD.
```

**Improved prompt:**

```text
Explain the purpose of OpenROAD in digital Physical Design.
Describe its major workflow stages, typical inputs and outputs,
and possible applications of machine learning. Use official
documentation for tool-specific claims and distinguish
documented capabilities from potential applications.
```

**Expected improvement:** This prompt narrows the topic and asks for evidence to support technical claims.

## 5. Comparing AI Tools

When comparing two AI tools, I should give both tools the same question and examine their answers using the following criteria.

| Criterion | What I Should Check |
|---|---|
| Accuracy | Does the answer agree with reliable technical sources? |
| Clarity | Is the explanation easy to understand? |
| Completeness | Are important concepts or steps missing? |
| Sources | Are the references relevant and trustworthy? |
| Consistency | Do both explanations agree on the main technical facts? |

A longer answer is not necessarily a better answer. Accuracy and relevance are more important than length.

## 6. Verifying an AI-Generated Claim

**Claim:** OpenROAD is an open-source project for digital design implementation.

**Verification source:** [Official OpenROAD Documentation](https://openroad.readthedocs.io/en/latest/)

### Verification Process

1. Identify the main technical claim.
2. Open the official documentation.
3. Check whether the documentation describes the tool and its implementation workflow.
4. Compare the documented information with the AI-generated answer.
5. Record the conclusion and any limitations.

**Conclusion:** The official documentation describes OpenROAD and its digital implementation capabilities, supporting the main claim. Individual features and workflow details should still be checked against the relevant documentation.

## 7. Responsible Use of AI

- Do not accept every AI-generated answer as correct.
- Verify important claims using official documentation.
- Test generated code before using it.
- Avoid uploading confidential RTL, netlists, timing constraints, proprietary design data, or restricted documents to public AI services.
- Do not run commands or scripts that I do not understand.
- Be transparent about AI assistance and take responsibility for the final work.

## 8. Conclusion

AI tools can improve my learning when I use clear prompts and verify their responses. Prompt refinement helps me obtain more relevant explanations, while source checking helps identify unsupported claims. I should use AI as a learning assistant rather than a replacement for my own understanding.
