# Week 03 Reflection

# 1. Which AI Tool Was Most Useful to Me, and for What Task?

ChatGPT can be useful for explaining technical concepts in simple language, organising information into tables, and helping me understand programming examples.

For my Physical Design learning, I can use it to clarify concepts such as floorplanning, placement, clock tree synthesis, and routing. I should verify technical information using official documentation before relying on it.

# 2. What Change to a Prompt Improved the Answer Most?

Adding context and specifying the expected output format can improve an answer.

For example, instead of asking only, "Explain Physical Design," I can request a beginner-friendly explanation of each stage, with the purpose of each stage presented in a Markdown table.

This makes the response more focused and easier to revise.

# 3. What Is One Claim I Verified, and What Did the Source Establish?

Claim checked: OpenROAD is an open-source project for digital design implementation.

Source: "OpenROAD Official Documentation" (https://openroad.readthedocs.io/en/latest/)

The documentation describes OpenROAD and its implementation capabilities. This supports the main claim, although individual features and workflow details must be checked separately.

This process taught me that an AI-generated answer should be treated as a starting point for investigation rather than automatic proof.

# 4. What Did I Learn About the Open-Source VLSI Tool?

I investigated OpenROAD for my Physical Design track. I learned about its role in automating digital implementation and the major stages involved in Physical Design.

I also understood that engineers need to examine timing, area, routing, and design-check results to evaluate the implementation.

My investigation was documentation-based. I still need to run a practical example to gain hands-on experience.

# 5. What Are Two Questions I Want Answered in the ML Masterclass?

1. How can machine learning help predict routing congestion or timing violations during Physical Design?
2. How can we evaluate whether an ML model's predictions are reliable enough to support real EDA workflows?

# 6. Overall Learning Experience

This week helped me understand that AI tools can support technical learning, research, and programming. However, their answers must be verified, and generated code must be reviewed before use.

I also connected AI and ML with my Physical Design track by identifying possible applications such as congestion prediction, PPA estimation, and design-space exploration.

I want to improve my Python skills, explore open-source VLSI tools practically, and understand how ML can support engineering decisions without replacing engineering verification.
