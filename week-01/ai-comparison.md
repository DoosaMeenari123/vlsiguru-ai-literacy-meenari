# Week 01 AI Assistant Comparison

## Common question

**What is the default port number used by HTTPS?**

## Tool 1

**Name:** ChatGPT

**Answer summary:**  
ChatGPT answered that HTTPS normally uses port 443.

**Strengths:**  
The answer was short, clear, and easy to understand.

**Weaknesses:**  
The answer was simple and did not provide detailed evidence by itself.

## Tool 2

**Name:** Gemini

**Answer summary:**  
Gemini also answered that HTTPS normally uses port 443.

**Strengths:**  
The answer was direct and easy to understand.

**Weaknesses:**  
The answer was brief and needed an external source for verification.

## Verification source

**IANA Service Name and Port Number Registry**  
IANA confirms that HTTPS uses port 443.

## Final comparison

- **Accuracy:** Both tools gave the correct answer.
- **Traceability:** The answer needed to be checked with IANA for reliable evidence.
- **Explanation quality:** Both answers were simple and easy to understand.
- **Ease of verification:** The claim was easy to verify using the IANA registry.
- **Which claims required correction or qualification?** None of the answers required correction in this experiment.

## Lesson

I learned that different AI assistants can give similar answers, but I should still verify important information using a reliable source. An answer sounding confident does not automatically mean it is correct.
